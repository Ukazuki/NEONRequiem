# NEON REQUIEM

人生シミュレーションを主軸にした、サイバーパンク人生ローグライクの初期プロトタイプです。

## 現在のプロトタイプ
- モバイルファーストのレスポンシブUI。スマートフォンの縦画面とPCの両方に対応
- 名前・出生環境を選んで人生を開始
- 月単位の自動進行、仕事・探索・休息・人物交流
- 重大イベントで時間を停止し、選択肢を提示
- 個別人物「ナオ」との信頼・親密さ、選択による分岐
- 死亡後の昇天、残響獲得、ギフトの解禁と次周への持ち越し
- ブラウザ内の自動保存、JSON形式の記録書き出し
- PWA manifest / service worker によるホーム画面追加・オフライン起動の土台

## 起動
静的サーバーでこのディレクトリを配信し、ブラウザで開いてください。GitHub Pages でも配信可能です。PWAのインストールとService WorkerはHTTPS配信環境で動作します。

## データ
セーブは現在のブラウザの localStorage に保存されます。ブラウザデータの消去や別端末への自動同期には対応していません。「記録を書き出す」でJSONバックアップを作成できます。

## 現在の制限
これはゲームループの手触りを確認するための試作です。装備生成・実際の戦闘・広い昇天ツリー・人物ごとの長編分岐・クラウド同期は未実装です。数値バランスとイベント内容も今後調整します。
